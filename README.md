# Interactive-Art-Map

An interactive map of India showcasing six regional Indian art traditions, built as a single self-contained HTML page for the course **21LEM301T – Indian Art Form**.

Click a location on the map to explore its art form, period and history:

| Location | State | Art Tradition |
|---|---|---|
| Lothal | Gujarat | Harappan Art & Craft |
| Pattadakal | Karnataka | Chalukyan Architecture & Sculpture |
| Lepakshi | Andhra Pradesh | Vijayanagara Murals & Temple Art |
| Puri | Odisha | Pattachitra Painting |
| Kangra | Himachal Pradesh | Kangra Miniature Painting |
| Jaipur | Rajasthan | Rajasthani Miniature Painting |

## Features
- Clickable map markers and labels that open an animated content panel
- Previous/next navigation between locations (buttons or arrow keys)
- Responsive layout for desktop and mobile
- No build step or dependencies (only the Cinzel font is loaded from Google Fonts)

## Usage
Download `art_map.html` and open it in any modern browser.
